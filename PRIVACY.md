# Privacy Policy

YouTube Researcher AI by D04 Products is designed to process only the content needed for the features the user chooses.

## What the extension reads
- The current YouTube video title, URL, thumbnail, channel, view count, publish date, and available transcript/captions.
- Search result metadata shown by YouTube when the user searches from the extension panel.
- Text typed by the user into the question or research fields.

## What is sent to AI providers
When the user clicks Full, Extreme, Ask, Research, or Read, the extension sends only the required transcript, generated text, question, or research prompt to the provider configured by the user.

Supported provider types include DeepSeek, OpenAI-compatible endpoints, OpenRouter, xAI/Grok, Anthropic Claude, local OpenAI-compatible servers, ElevenLabs, and custom HTTPS endpoints.

## What is stored locally
- API settings and selected model/voice IDs.
- Video summaries, answers, research briefs, and generated audio history.

This history is stored locally in the user's browser extension storage and IndexedDB.

## API keys
API keys are stored in the browser extension storage. Keys are sent only to the provider endpoint selected by the user when the user runs a feature that requires that provider.

No browser extension can make locally stored keys impossible to inspect by someone who controls the device or browser profile. For highest security, users should use restricted API keys, provider spend limits, and rotate keys when needed.

## Data sale
The extension does not sell user data.
